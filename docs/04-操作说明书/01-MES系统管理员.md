# 01 MES 系统管理员操作手册

> 角色：`mes_admin`｜数据范围：全部数据｜菜单：「制造执行」全部分组下的所有页面。
> 定位：MES 业务域的管理员——负责**基础数据建模**（系统运行的地基）、**AI 智能化设置**、**系统集成配置**，并对全部模块拥有完整操作权限。**不负责**基座侧的用户/角色/套餐管理（那是租户管理员的事）。

## 一、职责与页面清单

| 职责 | 页面 |
| --- | --- |
| 制造建模（工厂/车间/产线/工位）、物料、BOM、工艺路线、日历班次维护 | 基础数据 |
| 各业务域疑难操作兜底（全模块完整权限，含批量与导入导出） | 全部页面 |
| AI 能力开启配合、六场景智能体映射 | AI 智能化设置 |
| ERP 入站同步/结果回传配置、同步日志与重推 | 系统集成 |
| 设备数采：模拟上报验证、额定产能配置 | 设备数采监控 |
| 安灯、SPC 的管理兜底 | 安灯管理 / SPC 分析 |

## 二、基础数据建模（系统上线第一步）

> 路径：制造执行 → **基础数据**。5 个页签：工厂建模、物料、BOM、工艺路线、日历班次。全部支持 Excel 导入导出（日历班次除外）。

### 2.1 建议的初始化顺序

1. **工厂建模**：搭建「工厂 → 车间 → 产线 → 工位」四级树（工位后续可关联设备）。
2. **物料**：登记原料/半成品/成品，设定追溯粒度（按批次 / 按序列号）。
3. **BOM**：为需要按单生产的成品/半成品建物料清单（选父项物料、加子件与用量）。
4. **工艺路线**：定义工序步骤（工序名、产线、标准工时秒、是否质检点），**点「发布」后才可被工单引用**。
5. **日历班次**：按月维护每日班次（如 D 白班 08:00-16:00 / N 夜班），作为排产与产能基准。

### 2.2 工厂建模页签

- 筛选：按类型（工厂/车间/产线/工位）过滤。
- 「**新增节点**」：类型（必填）、上级（选工厂/车间/产线）、编码（必填，唯一）、名称（必填）、备注。
- 行内「编辑」「删除」；「批量删除」先勾选。删除有引用校验：**有下级或被引用的节点自动跳过**。

### 2.3 物料页签

- 筛选：关键字（编码/名称）。
- 「**新增物料**」：编码（必填唯一）、名称（必填）、规格、单位、类型（原材料/半成品/成品）、追溯粒度（按批次/按序列号）、备注。
- 导出可携带当前关键字筛选结果；批量删除时**被 BOM/工艺路线/检验方案/工单引用的物料自动跳过**。

### 2.4 BOM 页签

- 「**新增 BOM**」：编码、父项物料（搜索选择）、版本（默认 V1.0）；下方子件表格「**加一行**」逐个添加子件物料与用量，行内可删。
- 编辑时会加载 BOM 头 + 全部子件行。批量删除时**被工单引用的 BOM 自动跳过**。
- 导入为一行一个子件、按 BOM 编码归组整体保存。

### 2.5 工艺路线页签

- 「**新增路线**」：编码、名称、版本；工序行表格逐行填：工序名、产线（可空）、标准工时(秒)、**质检点勾选**（勾上的工序在报工时自动生成检验单）。
- 「**发布 / 停用**」：草稿态显示「发布」，已发布显示「停用」，点击即切换。
- 关键规则：**只有已发布的路线才会出现在工单的工艺路线下拉里**；已发布或被工单引用的路线删除时自动跳过。

### 2.6 日历班次页签

- 按月份查看；「**新增班次**」：日期、班次编码（如 D/N）、名称（如 白班）、开始/结束时间、类型（工作/休息）。
- 仅支持删除（单条/批量），无导入导出。

## 三、AI 智能化设置

> 路径：制造执行 → **AI 智能化设置**。两块内容：能力状态、场景 → 智能体映射。

### 3.1 开启 AI 能力（配合租户管理员）

AI 能力默认关闭（所有 AI 按钮置灰）。开启方式：在基座「**参数设置**」把参数 **`mes.ai.mode`** 设为以下之一（本租户可自建同名参数覆盖平台默认值）：

| 取值 | 含义 |
| --- | --- |
| `off` | 关闭（默认） |
| `auto` | 优先走 AI 服务，失败自动回退直连模型 |
| `platform` | 仅走 AI 服务（不回退） |
| `direct` | 仅直连模型（需配置 spring.ai 兼容参数） |

设置页「能力状态」卡会实时显示两个通道（AI 服务通道 / 直连模型通道）是否可用。各场景默认智能体由 MES 模块随服务启动**自动注册**到 AI 平台「智能体管理」（默认已发布，无需手工创建；想调整提示词或绑定模型/知识库，到 AI 平台编辑本租户副本）。

### 3.2 八场景智能体映射

| 场景 | 用途（所在页面） | 默认智能体编码 |
| --- | --- | --- |
| AI 生产日报/周报 | 看板报表页 | mes_report_writer |
| AI 质量异常诊断 | 质量管理页 | mes_quality_diag |
| AI 设备故障诊断 | 设备管理页 | mes_equip_diag |
| AI 智能问数 | 看板报表页（自然语言查生产数据，绑定 mes_query 受控取数工具） | mes_data_analyst |
| AI 排产建议 | 生产计划页 | mes_schedule_advisor |
| AI 工艺/SOP 知识问答 | 报工工作台 | mes_kb_qa |
| AI 安灯异常摘要 | 安灯管理页（三期） | mes_andon_summary |
| AI SPC 判读 | SPC 分析页（三期） | mes_spc_interpret |

操作：每行「调整映射」下拉选择 AI 平台已发布的智能体（可清空=恢复默认）→ 点「保存」，**保存即生效**。映射仅作用于智能体链路；直连模式不经过智能体。

## 四、系统集成（对接 ERP）

> 路径：制造执行 → **系统集成**。上半「集成配置」，下半「同步日志」。

### 4.1 集成配置

- **启用入站同步**（开关）：开启后 ERP 可经开放平台把生产订单、物料、BOM 推入 MES（同外部单号重复推送自动幂等）；停用后引入接口直接拒绝。
- **启用结果回传**（开关）+ **回传目标 URL** + **签名密钥**：工单完工（报工达产）时向目标 URL 推送 JSON；失败自动退避重试、超限转死信；密钥用于 HMAC-SHA256 签名（留空保持原值）。
- 点「**保存配置**」生效。

### 4.2 同步日志与重推

- 筛选：方向（入站 ERP→MES / 出站 MES→ERP）、类型（订单/物料/BOM/结果回传）、状态（待推送/成功/失败待重试/死信）、业务单号。
- 失败行：等重试周期到点自动重试；也可点「**手动执行同步**」立即重试到期失败行；出站日志行内「**重推**」可单条强制重发。
- 入站订单落库为**草稿态工单**，需计划员在「生产计划」确认后提交下达。

## 五、设备数采监控（配合三期 IoT）

> 路径：制造执行 → **设备数采监控**。管理员拥有全部能力，日常运行建议交设备管理员（见 07 号手册），本手册只列管理员特有的两件事：

- **模拟上报**（「实时监控」页签）：选设备、状态、累计产量后上报——用于部署后验证数采链路（与 IoT 网关走同一通道）。
- **设备配置**页签：维护「额定小时产量」（OEE 性能因子分母）与「启用监控」开关。**未配额定产能时 OEE 性能按 1 计**。

## 六、管理员注意事项

1. **建模先行**：建模错误会传导到派工、报工、追溯全线（如路线未发布导致无法建单），投产前逐项核对。
2. **编码唯一**：物料、建模节点、BOM、路线、设备、检验方案的新增/编辑都按编码查重，重复编码会被拒绝。
3. **删除有引用校验**：所有批量删除均为部分成功语义，被引用的行跳过并给出原因；删除工艺路线前先确认未被工单引用或已停用。
4. **AI 红线**：各 AI 场景映射的智能体必须在 AI 平台**发布**后才生效；AI 输出一律为草稿/建议，不会自动改业务数据。
5. **停用 vs 删除**：工艺路线用「停用」保留历史追溯关系，尽量不删除已发布路线。
