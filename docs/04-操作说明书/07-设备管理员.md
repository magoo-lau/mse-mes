# 07 设备管理员操作手册

> 角色：`mes_equipment`｜数据范围：本部门｜可见菜单：基础数据（建模只读）、设备管理、看板报表（设备统计）、设备数采监控。
> 定位：设备全生命周期管家——设备台账、点检保养计划、维修工单闭环，三期起叠加数采监控与 OEE 管理。

## 一、职责与页面清单

| 页面 | 你能做什么 |
| --- | --- |
| 设备管理 | **设备台账**（维护+导入导出）、**点检保养计划**与启停、执行打卡、**维修工单**（报修/受理/完工）、AI 设备诊断 |
| 设备数采监控 | **实时监控**、**OEE 统计**、数采明细、**设备配置**（额定产能/启用监控）、模拟上报验证 |
| 基础数据 | 只读查询制造建模（设备关联产线/工位的参照） |
| 看板报表 | 设备维修统计 |

## 二、设备台账

> 设备管理 →「设备台账」页签。

- 「**新增设备**」：编码（必填唯一）、名称（必填）、型号、购置日期、备注。状态（运行/待机/维修/停机）由业务自动流转，无需手改。
- 行内「编辑」「删除」；批量删除时**被点检计划/维修工单/数采配置引用的设备自动跳过**。
- 支持 Excel **导入 / 导出**（导入按编码覆盖可选）。

## 三、点检保养

> 设备管理 →「点检保养」页签，上半是计划、下半是执行记录。

### 3.1 制定计划

「**新增计划**」：名称（必填）、设备（必填下拉）、类型（**点检** / **保养**）、周期（**日 / 周 / 月**）、下次执行日期、内容（如「检查油位、皮带张力」）→ 保存。计划默认启用；行内或批量「启用 / 停用」切换。

### 3.2 执行打卡

点「**执行打卡**」→ 选设备、结果「**正常** / **异常**」、填说明 → 提交。打卡结果为「**异常**」时系统**自动生成维修工单**（提示「已打卡（异常自动生成维修工单）」），无需再手工报修。执行记录留痕：日期、设备、结果、说明。

## 四、维修工单闭环

> 设备管理 →「维修工单」页签。

| 状态 | 操作 |
| --- | --- |
| 报修 | 「**受理**」——接单开始维修（点击即受理） |
| 维修中 | 「**完工**」——填写处理说明后完成；系统自动累计**停机时长（分钟）** |
| 已完工 | 只读归档 |

- 「**设备报修**」按钮可代工人报修（设备 + 故障描述）。
- 行内「**AI 设备诊断**」：AI 结合设备台账、历史维修记录给出故障假设与维修建议——仅供参考，作为维修方案的辅助。
- 状态变化与设备联动：维修中设备显示「维修」状态，完工后恢复。

## 五、设备数采监控与 OEE（三期）

> 设备数采监控页，4 个页签。

### 5.1 实时监控

- 列：设备、**在线**（窗口内有数采=在线）、状态、**状态源**（iot=实时数采 / manual=台账手工）、最近上报时间、今日产量增量、额定产能。
- 点「刷新」手动拉取；「**模拟上报**」用于验证数采链路（选设备/状态/累计产量），与 IoT 网关走同一通道——联调时用。

### 5.2 OEE 统计

- 筛选时间范围：近 7 / 14 / 30 天。
- 每台设备一行：**可用率 × 性能 × 质量 = OEE**（OEE 标签颜色：≥65% 绿 / ≥40% 黄 / <40% 红），附产量增量、维修停机时长、数采点数。
- **性能因子依赖「设备配置」里的额定小时产量**——未配置时按 1 计并标注「估算」；设备级质量因子暂按全厂报工口径。

### 5.3 数采明细与设备配置

- 数采明细：按设备筛选，看每次上报的状态、累计计数、增量、时间（分页）。
- 设备配置：维护每台设备的「**额定小时产量**」与「**启用监控**」开关，行内保存。**新设备接入数采前先在这里启用监控并配好额定产能**，OEE 口径才完整。

## 六、日常工作节奏建议

1. 每日：看「实时监控」的离线设备与「维修工单」待受理项；点检计划到期督促打卡。
2. 每周：看 OEE 红黄设备清单，结合维修统计（看板报表 → 设备维修统计，近 30 日维修次数/停机时长）安排预防性维护。
3. 每月：复核点保计划执行记录的异常率，调整周期与内容。

## 七、注意事项

1. **异常打卡自动生成维修工单**：点检人员选「异常」时请附说明，维修接单才有依据。
2. **完工必须填处理说明**：这是设备履历的一部分，影响 AI 诊断与后续统计。
3. **停机时长自动累计**：报修→维修中→完工之间为停机窗口，不要拖延点击状态，否则 OEE 偏差。
4. **额定产能要及时配置**：新设备先配额定产能再统计 OEE，否则性能因子失真。
5. 删除设备前先解除引用（点保计划、维修工单、数采配置），否则批量删除会被跳过。
