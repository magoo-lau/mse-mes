# 04 操作说明书 —— 总览与使用指南

> MSE-MES 制造执行系统**分角色操作说明书**总览。每本手册面向一个业务岗位，讲清「这个岗位能做什么、在哪个页面做、按什么顺序做」。
> 功能全景见 [01-功能规划](../01-功能规划.md)；角色授权设计依据见 [03-角色规划](../03-角色规划.md)。手册描述以当前系统实际界面为准。

## 二、进入系统

1. 用企业账号登录**基座门户**（浏览器访问门户地址）。
2. 登录后在左侧导航找到「**制造执行**」分组目录，展开即见本系统全部页面菜单（基础数据、生产计划、生产执行、报工工作台……）。菜单按你的角色授权显示——看不到某个菜单表示该角色未授权或套餐未包含。
3. 界面为微前端嵌入运行：导航、登录态、深浅色主题均由基座统一管理，MES 页面内不再单独登录。
4. 页面顶部「接入信息」页（/home）仅用于显示当前登录用户、租户与嵌入模式的自检信息，日常操作用不到。

## 三、系统业务全景（一期闭环 + 二三期增强）

```
基础数据建模（工厂/产线/物料/BOM/工艺/日历）
  → 生产订单（创建→提交→下达）
  → 排产计划（产线×班次，草稿→发布）      ← AI 排产建议（草稿）
  → 派工（指派工位）→ 领料（线边仓出库）
  → 工序开工 → 报工（合格/不良）→ 工序转移 → … → 报工达产完工
  → 质检点自动生成检验单 → 检验录入 → 不良处置（返工/报废/让步）
  → 质量异常登记/处理/关闭
  → 批次追溯 / 看板报表                   ← AI 日报、AI 问数
配套：设备台账/点保/维修，安灯，SPC，IoT 数采与 OEE，ERP 系统集成
```

## 四、通用操作（所有页面一致）

### 4.1 列表与筛选

- 筛选区在列表上方：文本框输入后按**回车**或点「查询」触发；下拉筛选**选中即自动刷新**；点清除图标恢复全部。
- 列表分页显示；部分页面（质量、设备、物料、追溯）固定加载前 100 条，数据量大时请配合筛选缩小范围。

### 4.2 批量操作

- 先在列表**勾选**行，再点工具栏批量按钮（未勾选时按钮置灰）。
- 系统对批量执行采用「**部分成功**」语义：状态不允许、被其他数据引用的行会被**自动跳过**并在结果中说明原因，不会导致整批失败。全部成功提示「成功 N 条」；部分失败弹窗逐条列出失败原因。

### 4.3 Excel 导入 / 导出（基础数据类页面）

主数据类页面（基础数据页的制造建模、物料、BOM、工艺路线，设备管理页的设备台账，质量管理页的检验方案）提供「导入 / 导出」按钮：

1. 点「**导入**」→ 在对话框点「**下载导入模板**」，按模板列填写（`*` 为必填列，类型等枚举列**填中文**，如「原材料」「白班」）。
2. 拖拽或点击选择填好的 Excel（.xlsx/.xls，仅 1 个文件）。
3. 可选勾选「**更新已存在的数据（按编码覆盖）**」：勾上后相同编码的记录会被覆盖更新；不勾则重复编码报错跳过。
4. 点「**开始导入**」→ 显示「导入完成：成功 X 条，失败 Y 条」，失败原因逐条列出。
5. 点「**导出**」直接下载当前数据的 Excel 文件。

### 4.4 AI 功能通用说明

- AI 按钮（AI 排产建议、AI 日报、AI 诊断、AI 问数、AI 问答等）在**能力开启**后可用；未开启时按钮置灰。
- AI 结果统一弹窗展示，加载提示「AI 正在分析，请稍候…」，底部固定标注：**「以上内容由 AI 生成，仅供参考，请人工确认后再执行相关操作。」**可点「复制内容」带走结果。
- **红线**：AI 只产出草稿/建议——排产建议需人工勾选应用、日报需人工确认，AI 不会直接改动业务数据。
- 能力开关与场景配置由 MES 系统管理员维护（见 [01-MES系统管理员](01-MES系统管理员.md) 第 5 节）。

### 4.5 外观

深浅色模式与主题色跟随基座门户设置（门户右上角切换），MES 页面自动跟随，无需单独设置。

## 五、状态字典速查（界面标签的准确含义）

| 业务对象 | 状态枚举 |
| --- | --- |
| 生产订单 | 草稿 → 已提交 → 已下达 → 生产中 → 完工；另有 已关闭、已取消 |
| 排产计划 | 草稿 → 已发布（仅草稿可编辑/发布/删除） |
| 派工单 | 待开工 → 生产中 → 已完成（仅前两种可派工/转入） |
| 报工记录 | 待审核 → 已审核；被驳回为 已驳回（驳回/撤销数量回冲） |
| 检验单 | 待检 → 已完成（结论：合格 / 不合格 / 让步接收） |
| 不良记录 | 待处置 → 已处置（处置方式：返工 / 报废 / 让步接收） |
| 质量异常单 | 已登记 / 处理中 → 已关闭（级别：一般 / 重大 / 危急） |
| 工艺路线 | 草稿 → 已发布（发布后才能被工单引用，可停用） |
| 设备 | 运行 / 待机 / 维修 / 停机 |
| 维修工单 | 报修 → 维修中 → 已完工（自动累计停机时长） |
| 点保计划 | 启用 / 停用；执行结果：正常 / 异常（异常自动生成维修工单） |
| 领退料单 | 已申请 → 已执行 / 已驳回（类型：领料 / 退料） |
| 序列号 SN | 在制 / 完工 / 报废 |
| 同步日志 | 待推送 / 成功 / 失败待重试 / 死信（方向：入站 ERP→MES / 出站 MES→ERP） |
| 安灯呼叫 | 待响应 → 处理中 → 已关闭（超时 15 分钟自动升一级，最多二级） |
| 停工记录 | 停工中 → 已恢复（原因：设备故障 / 缺料 / 质量异常 / 计划变更 / 其他） |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 左侧看不到某个 MES 菜单 | 该角色未授权此菜单，或租户套餐未包含。联系租户管理员在「角色管理 / 套餐管理」检查。 |
| 列表里看不到别人的数据 | 角色数据范围限制：操作工「仅本人」，调度/质检/设备/仓管「本部门」，计划员/车间主任「本部门及以下」，系统管理员与管理层「全部」。属正常设计。 |
| 看不到某个按钮 | 按钮按权限显隐：无该操作权限的角色不显示按钮（如只有「查询」无「新增」）。找租户管理员补授权。 |
| AI 按钮全部置灰 | AI 能力开关（参数 `mes.ai.mode`）默认关闭，由 MES 系统管理员开启（见 01 号手册）。 |
| 批量操作后部分条目没执行 | 部分成功语义：状态不允许或被引用的行被跳过，结果弹窗中有逐条原因，处理后可再次执行剩余项。 |
| 导入后有些行失败 | 查看失败明细：必填缺失、枚举列未填中文、编码重复（未勾选「更新已存在」）、编码被引用等，修正后重新导入。 |
| 工单新建时选不到工艺路线 | 只有「已发布」状态的工艺路线才出现在下拉中。请 MES 系统管理员先发布路线。 |
| 驳回报工后工单数量变了 | 驳回与撤销都会**回冲数量**（完工数/合格数等回退），属正常业务规则。 |
| 报工后出现了待检检验单 | 该工序在工艺路线里被标记为「质检点」：报工经过质检点时系统自动生成 IPQC 检验单，由质检员录入结果。 |
| 点检打卡「异常」后多了维修工单 | 设计如此：点检/保养结果为异常时自动生成维修工单，转设备管理员处理。 |

## 七、阅读建议

- 新岗位上手：先读本手册第二节、第三节建立全局认识，再读对应角色手册的「典型操作流程」。
- 遇到具体按钮/字段疑问：查角色手册的「页面操作详解」小节，按钮文字与界面一致，可直接对照。
- 状态流转拿不准：查第五节状态字典。
