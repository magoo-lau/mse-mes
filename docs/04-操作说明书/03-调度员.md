# 03 调度员操作手册

> 角色：`mes_dispatcher`｜数据范围：本部门｜可见菜单：生产计划（只读）、生产执行、报工工作台（审核）、质量管理（异常只读）、设备管理（状态只读）、追溯查询、看板报表、安灯管理。
> 定位：车间现场的总调度——派工到工位、工序间流转、异常停工处置、报工审核把关、安灯响应，让产线按排产跑起来。

## 一、职责与页面清单

| 页面 | 你能做什么 |
| --- | --- |
| 生产执行 | **派工指派、工序转移**、生产进度/在制品查看、异常停工登记与恢复 |
| 报工工作台 | 报工记录**审核**（通过/驳回、批量通过/批量驳回） |
| 生产计划 | 只读查看工单与排产（口径参考） |
| 质量管理 | 只读查看质量异常单 |
| 设备管理 | 只读查看设备状态 |
| 追溯查询 | 批次反向追溯查询 |
| 看板报表 | 看板与统计查看 |
| 安灯管理 | 安灯**响应/关闭**、超时升级扫描 |
| 报工工作台 | AI 工艺/SOP 问答 |

## 二、典型流程

### 2.1 接单派工

1. 生产计划已由计划员下达（工单状态=已下达，系统已按工艺路线自动生成各工序派工单）。
2. 生产执行 →「**派工**」页签 → 找到待开工的派工单 → 行内「**派工**」→ 选择**产线、工位** → 保存。派工单即绑定到具体工位。
3. 工人可在报工工作台看到自己工位的待开工任务并开始报工。

### 2.2 工序间转移

1. 上道工序报工完成后，在「派工」页签对该行点「**转入**」。
2. 弹窗选择**转入工序**（候选=同一工单内其他**待开工**工序）、**转移数量**（必填，默认 1）、备注 → 确认。
3. 转移全程留痕；如需跳站或回退，转移目标也必须是同工单的待开工工序。

### 2.3 异常停工与恢复

1. 产线出问题时：「异常停工」页签 →「**登记停工**」→ 选**原因**（设备故障/缺料/质量异常/计划变更/其他）、产线、备注 → 登记。
2. 问题解决后点该行「**恢复**」（仅「停工中」的记录可恢复）。停工时长进入看板与设备统计口径。

### 2.4 报工审核（如租户开启审核制）

1. 生产执行 → 报工工作台 →「报工记录」区，筛选状态=待审核。
2. 逐条核对合格数/不良数/不良原因后：点「**通过**」确认；发现误报点「**驳回**」并**填写驳回原因**（驳回后数量自动回冲，工人可重报）。
3. 批量处理：勾选多条待审核记录 →「批量通过」或「批量驳回」（同样需填原因）；非待审核状态的行自动跳过。
4. 免审租户（未配置报工审核）报工直接生效，此环节无待审核记录。

### 2.5 安灯响应（三期）

1. 安灯管理 →「活跃呼叫看板」：待响应呼叫红色高亮，超时 15 分钟自动升一级（最多二级）。
2. 对待响应呼叫点「**响应**」→ 进入处理中；处理完毕点「**关闭**」并可填处理结果（可空）。
3. 可点「**执行超时升级扫描**」手动触发一轮升级判定（平时后台每 30 秒自动扫描）。

## 三、页面操作详解

### 3.1 生产执行 → 派工页签

- 筛选：状态（待开工/生产中/已完成）。
- 列：工单、工序号、工序、产线、工位、派工数、已报工、状态。
- 行内「派工」「转入」仅在**待开工/生产中**状态显示。

### 3.2 生产执行 → 生产进度页签

工单级进度列：工单号、计划数、完工数、合格数、不良数、状态；「工序进度」列以标签展示每道工序的「已报工数/计划数」（绿色=完成、橙色=生产中）。用于催单与瓶颈判断。

### 3.3 生产执行 → 在制品页签

按产线筛选，查看各工单、各工序的在制数量分布——判断哪道工序积压。

### 3.4 报工工作台 → 报工记录

- 筛选：状态（待审核/已审核/已驳回）。
- 列：报工单号、工单、合格、不良、不良原因、状态。
- 状态与操作：待审核 → 通过/驳回/撤销（撤销数量回冲）；已审核 → 撤销；已驳回 → 无操作（等待工人重报）。

### 3.5 AI 工艺/SOP 问答

报工工作台顶部「**AI 工艺/SOP 问答**」：输入问题（如「这道工序的标准工时是多少」）→ AI 基于工艺/SOP 知识库回答，弹窗展示、可复制。调度现场口径争议时可用它快速查证。

## 四、注意事项

1. **转移只能去待开工工序**：跨工单不能转移；转移数量不能超过已报工量。
2. **驳回必须给原因**：驳回原因会展示给操作工，驳回与撤销都会回冲数量。
3. **停工要登记**：口头停工不算数——停工记录是看板停工统计与设备 OEE 的数据来源。
4. **安灯升级有上限**：超时升级最多到二级，后台自动扫描；紧急问题不要只等安灯，直接电话/现场处置。
5. 数据范围是「本部门」：其他车间的派工/报工数据不可见属正常。
