# 08 仓管员操作手册

> 角色：`mes_warehouse`｜数据范围：本部门｜可见菜单：基础数据（物料/BOM 只读）、报工工作台（只读）、物料管理、追溯查询（只读）。
> 定位：车间线边仓管家——处理领退料申请、看管线边仓台账、调整库存，保证产线不断料、账实一致。

> 仓库主账归 ERP/WMS；MES 管的是**线边仓**（产线边的小仓库）与车间物流。

## 一、职责与页面清单

| 页面 | 你能做什么 |
| --- | --- |
| 物料管理 | **领料/退料申请**、**发料执行与驳回**（含批量）、**线边仓库存**查看、**库存调整**（盘盈盘亏）、库存流水查看 |
| 基础数据 | 只读查询物料、BOM（核对用量） |
| 报工工作台 | 只读查看报工记录（核对产出） |
| 追溯查询 | 批次追溯查询 |

## 二、领退料处理（核心操作）

> 物料管理 →「领退料」页签。

### 2.1 处理别人（操作工）的领料申请

1. 列表筛选状态=「**已申请**」的单子。
2. 核对物料、数量、批次后：点行内「**执行**」→ 发料出库，**线边仓库存与流水同时记账**；物料不对/数量不符 →「**驳回**」→ 确认（写明原因更好，操作工看得到状态）。
3. 批量处理：勾选多条 →「**批量执行**」/「**批量驳回**」→ 确认；非「已申请」状态的自动跳过。

### 2.2 你自己代提申请

- 「**领料申请**」：选物料、填数量 → 提交（自己申请后也可执行）。
- 「**退料申请**」：选物料、**批次（必填）**、数量 → 提交。余料/不良料退回时用，执行后线边仓冲减。

### 2.3 单子状态

| 状态 | 含义 | 可操作 |
| --- | --- | --- |
| 已申请 | 等待你处理 | 执行 / 驳回 |
| 已执行 | 已发料/收料完成 | 无 |
| 已驳回 | 已退回申请人 | 无 |

## 三、线边仓库存

> 物料管理 →「线边仓库存」页签。台账列：物料、批次、数量、仓位（只读查询，无行操作）。

**库存调整（盘盈盘亏）**：盘点发现账实不符时 →「**库存调整**」→ 选**物料**、批次（无批次物料留空）、**变动数（正=盘盈补账，负=盘亏扣账）**、备注 →「调整」。调整记入流水，来源为「手工调整」。

**库存流水**：第三页签只读——时间、物料、批次、变动数、结存、**来源**（领料 / 退料 / 报工产出 / 手工调整）、备注。所有库存变化都可在此对账。

## 四、库存是怎么动起来的（帮助你解答疑问）

| 来源 | 什么时候发生 |
| --- | --- |
| 领料 | 你点「执行」发料后，线边仓增加 |
| 退料 | 退料申请执行后，线边仓冲减 |
| 报工产出 | 操作工报工合格后，合格品自动按批次计入线边仓 |
| 手工调整 | 你做的盘盈盘亏调整 |

> 报工产出自动入库：操作工每报一次工，合格数就累计进对应批次——**成品/半成品的线边仓数量主要来自报工，不需要手工入库**。

## 五、批次追溯（配合查询）

追溯查询 → 输入批次号 →「追溯」→ 看该批次的来源（采购/生产）、关联工单、工序报工链、耗用原料。发料或盘点时对批次有疑问可用此页核实。

## 六、注意事项

1. **执行前核对数量与批次**：执行即记账（库存+流水同事务），执行错了没有单级冲销入口，需要用「退料」或「库存调整」纠正。
2. **退料必须填批次**：批次是追溯的钥匙，请按实物批次填写。
3. **盘盈盘亏用调整**：不要用退料/领料去平账——调整有独立流水来源，月度对账才清晰。
4. **驳回要反馈**：驳回后操作工能看到状态，重要申请建议当面/群里说明原因。
5. 数据范围「本部门」：其他车间线边仓数据不可见属正常。
6. 标签打印：系统提供物料/批次标签打印数据输出能力（对接条码打印机由部署侧配置），界面上暂无独立按钮。
