# 04 车间主任操作手册

> 角色：`mes_leader`｜数据范围：本部门及以下｜可见菜单：「制造执行」一期全部页面 + 安灯管理。
> 定位：车间第一责任人——报工审核把关、质量异常处置、跨工序协调，并用 AI 日报/问数掌握车间全貌。

## 一、职责与页面清单

| 页面 | 你能做什么 |
| --- | --- |
| 基础数据 | 只读（建模/物料/BOM/工艺/日历） |
| 生产计划 | 工单查询、**工单关闭**；排产只读 |
| 生产执行 | 派工、工序转移、进度/在制品、**异常停工登记与恢复**（与调度员同权） |
| 报工工作台 | **报工审核**（通过/驳回/批量）、**撤销**、返工跟进 |
| 质量管理 | **质量异常单全流程**（登记/处理/关闭）、检验单与不良处置查看、AI 质量诊断 |
| 设备管理 / 物料管理 | 只读（设备台账与状态、领退料与库存） |
| 追溯查询 | 批次追溯 + **追溯报告导出** |
| 看板报表 | 全部统计查看 + **AI 生产日报** + AI 智能问数 |
| 安灯管理 | 呼叫查看与**AI 安灯异常摘要** |

## 二、典型流程

### 2.1 报工审核（如租户开启审核制）

1. 报工工作台 → 右侧「报工记录」，筛选「待审核」。
2. 逐条核对：合格数、不良数、不良原因是否与现场一致。
   - 无误 → 「**通过**」。
   - 误报 → 「**驳回**」→ 填写驳回原因 → 数量自动回冲，操作工重报。
3. 批量：勾选多条 → 「**批量通过**」/「**批量驳回**」（驳回统一填一个原因）；非待审核记录自动跳过。
4. 当班误报未审核的，可让操作工自行「撤销」；已审核的误报由你点「**撤销**」（数量回冲）后重新报工。

### 2.2 不合格与返工跟进

1. 质检员在质量管理页提交检验结果后，不良自动生成「待处置」记录，由质检员处置（返工/报废/让步接收）。
2. 处置方式为「**返工**」的：通知操作工在报工时把「类型」选为**返工报工**重新报工，返工数量计入该工单。
3. 重大质量事件：在质量管理 →「质量异常」登记异常单（见 2.3）。

### 2.3 质量异常单管理

1. 质量管理 →「质量异常」页签 →「**登记异常**」：标题（必填）、级别（一般/重大/危急）、描述、原因分析、纠正措施。新单默认「处理中」。
2. 处理进展续填「原因分析 / 纠正措施」（行内「**处理**」）。
3. 闭环后行内「**关闭**」（或勾选「**批量关闭**」）；已关闭的单子只读。
4. 单子上可随时点「**AI 质量诊断**」：AI 结合异常描述与历史数据给出可能原因与处置建议，供分析参考（输出仅供参考）。

### 2.4 异常停工与产能协调

与调度员同权：生产执行 →「异常停工」→「登记停工」（原因：设备故障/缺料/质量异常/计划变更/其他）→ 恢复时点「恢复」。生产受阻需改计划时，与计划员沟通由其取消/关闭工单（你也有关闭权）。

### 2.5 AI 生产日报

看板报表 →「**AI 生成日报**」→ 系统汇总近 1 日的产量、合格率、不良 TOP、停工、异常等数据生成日报草稿 → 弹窗展示，可复制后粘贴到邮件/群发。日报为草稿性质，正式发布口径以确认后的内容为准。

### 2.6 AI 安灯异常摘要（三期）

安灯管理 →「**AI 异常摘要**」→ 汇总近 7 天安灯呼叫的类型分布、高频工位、平均响应时长，给出根因线索与改善建议。周例会前生成一次，作为现场改善输入。

## 三、页面操作详解

### 3.1 报工记录状态与操作

| 状态 | 可用操作 |
| --- | --- |
| 待审核 | 通过、驳回（填原因）、撤销 |
| 已审核 | 撤销（数量回冲） |
| 已驳回 | 无（等操作工重报） |

### 3.2 质量异常单

- 筛选：无（列表前 100 条）；列：单号、标题、级别、状态。
- 级别：一般 / 重大 / 危急；状态：处理中 → 已关闭。
- 操作按状态显示：处理、关闭仅在未关闭时可见；AI 诊断随时可用。

### 3.3 追溯与报告导出

追溯查询 → 输入批次号 →「**追溯**」→ 展示批次概要（物料/数量/来源/工单）、工序报工链、耗用原料 →「**导出报告**」下载 CSV（文件名含批次号）。客诉与审计场景直接把导出文件发出去即可。

### 3.4 AI 智能问数

看板报表顶部输入框自然语言提问，如「本车间近 7 天合格率」「当前未完成工单有哪些」。AI 只读受控供数，输出仅供参考。

## 四、注意事项

1. **审核制差异**：租户开启报工审核时，操作工报工需你审核后才计入产量；未开启则报工直过——审核策略由租户管理员配置。
2. **驳回要写清原因**：驳回原因是操作工重报的依据，尽量具体（如「不良数应为 3 不是 30」）。
3. **撤销有回冲**：通过/撤销都会回冲工单完工数、合格数与线边仓产出，操作前想清楚。
4. **异常单别积压**：重大/危急异常建议当天登记并跟踪；关闭前确认纠正措施已落地。
5. 数据范围「本部门及以下」：车间内部（含下属班组）全可见，兄弟车间不可见。
