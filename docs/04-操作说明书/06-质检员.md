# 06 质检员操作手册

> 角色：`mes_inspector`｜数据范围：本部门｜可见菜单：基础数据（只读）、报工工作台（只读）、质量管理、追溯查询、看板报表（质量统计）、SPC 分析。
> 定位：质量关口——维护检验标准、执行检验、处置不良、登记与闭环质量异常，并用追溯与 SPC 工具做质量分析与预防。

## 一、职责与页面清单

| 页面 | 你能做什么 |
| --- | --- |
| 质量管理 | 检验方案维护、**检验单录入**、**不良品处置**、质量异常全流程、AI 质量诊断 |
| 追溯查询 | 批次反向追溯、**追溯报告导出**、序列号查询与绑定 |
| SPC 分析 | 监控项维护、样本录入、X̄-R 控制图、Cp/Cpk、**AI SPC 判读** |
| 基础数据 | 只读查询物料、工艺路线（检验标准引用） |
| 报工工作台 | 只读查看报工记录（核对不良） |
| 看板报表 | 质量统计（不良 TOP 等） |

## 二、检验方案（标准维护）

> 质量管理 →「检验方案」页签。

- 「**新增方案**」：编码（必填唯一）、名称（必填）、**类型**（IQC 来料 / IPQC 过程 / FQC 完工）、抽样规则（如「按 GB2828 二级正常检查」）；下方「**加项目**」逐条添加检验项目（项目名 / 标准 / 方法）。
- 行内编辑、删除；批量删除（被检验单引用的自动跳过）。
- 支持 Excel **导入 / 导出**（导入按编码覆盖可选，多行同编码自动归组为一个方案）。

## 三、检验单执行（核心操作）

> 质量管理 →「检验单」页签。

**检验单从哪来**：操作工报工时，工序被标记为「质检点」的会**自动生成 IPQC 检验单**；状态=待检。

1. 筛选状态=「待检」，找到自己的检验单 → 行内「**录入**」。
2. 填写：**合格数量**、**不良数量**（均必填）、**结论**（合格 / 不合格 / 让步接收）、检验数据（记录实测值，选填）→「提交」。
3. 提交后：检验单完成；**不良数量自动生成待处置的不良记录**，进入「不良处置」页签。

## 四、不良品处置

> 质量管理 →「不良处置」页签。

- 状态=待处置的记录 → 行内「**处置**」→ 选**处置方式**（返工 / 报废 / 让步接收）+ 处置说明 → 确认。
- 多条同类不良 → 勾选后「**批量处置**」→ 统一选一种处置方式；已处置的自动跳过。
- 处置为「**返工**」的：通知操作工以「返工报工」类型重新报工；「报废」「让步接收」按说明留档。

## 五、质量异常单

> 质量管理 →「质量异常」页签。重大质量问题（批量不良、客诉苗头等）走异常单闭环：

1. 「**登记异常**」：标题（必填）、级别（一般/重大/危急）、描述、原因分析、纠正措施 → 新单为「处理中」。
2. 跟进处理（行内「处理」续填原因分析/纠正措施）；闭环后「**关闭**」，或勾选「**批量关闭**」（已关闭的自动跳过）。
3. 行内「**AI 质量诊断**」：AI 结合异常信息给出可能原因排序与处置建议——**仅供参考**，作为你填写原因分析/纠正措施的辅助。

## 六、批次追溯与序列号

> 追溯查询页。

- **批次追溯**：输入批次号 →「追溯」→ 展示批次概要（物料/数量/来源/关联工单）+「工序报工链」（每道工序的合格/不良/时间）+「耗用原料」（领料单/物料/数量）→「**导出报告**」下载 CSV。用于客诉溯源与问题原料影响面排查。
- **序列号**：按序列号关键字查询 SN 档案（物料/批次/状态：在制/完工/报废）；「**绑定序列号**」为按件管理产品补录 SN 与批次、物料的关联。

## 七、SPC 统计过程控制（三期）

> SPC 分析页，两个页签。

### 7.1 监控项（一次性配置）

「监控项」页签 →「新增监控项」：编码、名称（必填）、工序、质量特性（如「轴径」）、单位、**规格下限 / 规格上限 / 目标值**、**子组大小 n**（2-10，默认 5）、备注。行内编辑/删除、批量删除（连同其全部样本，有确认提示）。

### 7.2 样本录入与控制图

1. 「控制图」页签 → 选监控项 + 时间范围（近 7/30/90 天）。
2. 「**录入样本**」：选监控项 → 测量值**逗号或空格分隔**（建议一次录一个完整子组 n 个值）→ 提交；也可关联工单。
3. 图表区自动计算：X̄ 与控制限、R̄ 与 R 上限、**Cp/Cpk**（需配置双侧规格限）、**超限报警**（失控点数 / 超规格点数）；子组表中超限行红色高亮。
4. 「**AI SPC 判读**」：AI 判断控制图异常模式（趋势/游程/周期）并给出工艺调整建议——仅供参考。

> 规则说明（页脚原文口径）：控制限 = X̄̄ ± A2·R̄，R 图 UCL = D4·R̄（Shewhart 系数按 n 内置）；样本不足两个完整子组时不评定。

## 八、注意事项

1. **检验单只能录入一次**：提交后单据完成，录错需联系 MES 系统管理员处理（界面无改单入口）。
2. **不良先处置再返工**：不良记录处置为「返工」后操作工才返工报工；直接口头安排返工会造成账实不符。
3. **异常单及时闭环**：重大/危急异常请当天登记；关闭前确认纠正措施已执行。
4. **样本按子组录入**：SPC 按子组 n 计算控制限，零散录入会导致「样本不足」不评定；尽量按每次 n 个值录。
5. 数据范围「本部门」：其他车间的检验单/异常单不可见属正常。
