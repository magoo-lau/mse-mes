# 05 操作工操作手册

> 角色：`mes_operator`｜数据范围：仅本人｜可见菜单：生产执行（部分）、报工工作台、设备管理（点检/报修）、物料管理（领料申请）、看板报表、安灯管理（呼叫）。
> 定位：现场作业员——**报工、转移、领料、点检、呼叫安灯**五件事。界面为大按钮少输入设计，适合工位机/PDA/扫码场景。

## 一、你每天要做的事

| 事项 | 在哪做 |
| --- | --- |
| 开工前领料 | 物料管理 → 领料申请 |
| 干活 | （按派工单干活，无需系统操作） |
| 干完报工 | 报工工作台 → 快速报工 |
| 转下道工序 | 生产执行 → 派工 → 转入 |
| 设备点检打卡 | 设备管理 → 点检保养 → 执行打卡 |
| 设备坏了 | 设备管理 → 维修工单 → 设备报修 |
| 缺料/设备/质量问题求助 | 安灯管理 → 安灯呼叫 |
| 报错了要撤回 | 报工工作台 → 报工记录 → 撤销 |

## 二、快速报工（核心操作）

> 报工工作台 → 左侧「快速报工」卡片。

1. 「派工单」下拉：选择自己工位未完成的派工单（显示「工单号 / 工序名」）；没有工序的工单也可直接选单直报。
2. 「工位」：选派工单后自动带出，可改。
3. 「类型」：默认「**正常报工**」；处置为返工的活选「**返工报工**」。
4. 填「**合格数量**」「**不良数量**」；**不良数量大于 0 时必须填「不良原因」**。
5. 点「**提交报工**」→ 提示「报工成功」，输入清空可继续下一单。
6. 该工序在工艺路线中被标记为「质检点」的，报工后系统自动生成检验单，等质检员检验。

**报错了怎么办**：右侧「报工记录」里找到那条记录 →「**撤销**」→ 确认（数量自动回冲）→ 重新报工。待审核与已审核的都能撤销；被驳回的直接重报即可。

> 提示：如厂里开启了报工审核，报工后状态是「待审核」，等调度员/车间主任审核通过才计入产量；免审核厂点完立即生效。

## 三、工序转移

活干完了、下道工序在别的工位/产线做：

1. 生产执行 →「派工」页签 → 找到自己工序那行（状态=生产中）→ 点「**转入**」。
2. 选「转入工序」（同工单的下道待开工工序）、填**转移数量**、可加备注 → 确认「转移」。

## 四、领料申请

干活缺料时：物料管理 →「领退料」页签 →「**领料申请**」→ 选**物料**、填**数量** → 提交。仓管员审批发料后，料到线边仓即可领用。你能在本页看到自己申请的单子状态（已申请/已执行/已驳回）。

## 五、设备点检与报修

### 5.1 点检/保养打卡

设备管理 →「点检保养」页签 →「**执行打卡**」→ 选**设备**、结果选「**正常**」或「**异常**」、可填说明 → 提交。
打卡结果为「**异常**」时系统自动生成维修工单，无需你另外报修。

### 5.2 设备报修

设备坏了：设备管理 →「维修工单」页签 →「**设备报修**」→ 选**设备**、写清**故障描述**（如「主轴异响，无法启动」）→ 报修。设备管理员接单维修，修好后工单显示「已完工」。

## 六、安灯呼叫（求助）

线上有需要支援的情况（设备故障 / 质量问题 / 缺料）：安灯管理 →「**安灯呼叫**」→ 选**类型**（设备/质量/物料）、可选产线工位、简述情况 → 提交，提示「呼叫已发出」。
之后调度员或设备管理员会「响应」并处理，处理完呼叫单关闭。**超时 15 分钟没人响应会自动升级一级**（最多两级），不用反复呼叫。

## 七、其他

- **AI 工艺/SOP 问答**：报工工作台顶部按钮。不会做的活、不清楚工艺参数（如「这道工序的标准工时是多少」「SOP 第几步」）直接用大白话提问，AI 依据工艺/SOP 知识库回答，供参考。
- **生产进度**：生产执行 →「生产进度」可看自己参与工单的完成情况。
- **看板**：看板报表页可查看当日产量、合格率等车间大数。
- **标签打印**：系统支持物料/批次标签打印数据输出（对接条码打印机由厂里部署配置），界面上暂无独立按钮。

## 八、常见问题

| 问题 | 处理 |
| --- | --- |
| 派工单下拉里找不到自己的活 | 确认调度员已把该工序派工到你工位（状态=待开工/生产中）；未派工找调度员。 |
| 不良原因没填，提交不了 | 不良数量大于 0 时必须选/填不良原因。 |
| 报工后发现数量错了 | 报工记录 → 撤销（数量回冲）→ 重新报工。 |
| 报工显示「待审核」一直没动 | 厂里开了报工审核，提醒调度员/车间主任审核。 |
| 点检打卡选了「异常」 | 会自动生成维修工单，不用再报修；设备管理员会来处理。 |
| 领料被驳回 | 看驳回原因，联系仓管员或重新申请。 |
| 看不到别人的报工记录 | 操作工数据范围是「仅本人」，只能看到自己报的记录，属正常。 |
