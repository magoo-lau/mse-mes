# 09 管理层操作手册

> 角色：`mes_executive`｜数据范围：全部数据｜可见菜单：基础数据 / 生产计划 / 生产执行 / 质量管理 / 设备管理 / 追溯查询 / 看板报表（全部**只读**，无新增/修改/删除操作）。
> 定位：经营与管理视角——用看板、统计与 AI 汇报工具掌握「产了多少、质好不好、卡在哪里」，并在追溯场景直接取证导出。

## 一、你能看到的

| 页面 | 能看到什么 |
| --- | --- |
| 看板报表 | 六项当日核心指标、近 7 日产量趋势、不良 TOP、设备维修统计、AI 日报、AI 问数 |
| 生产计划 | 全部工单与排产（只读） |
| 生产执行 | 全部工单/工序进度（只读） |
| 质量管理 | 质量异常单（只读） |
| 设备管理 | 设备状态（只读） |
| 追溯查询 | 批次追溯 + **追溯报告导出** |
| 基础数据 | 制造建模（只读） |

## 二、看板报表（日常主页面）

> 看板报表页从上到下四块内容。

### 2.1 当日核心指标（顶部六卡）

| 指标 | 管理含义 |
| --- | --- |
| 今日合格数 / 今日不良数 | 当日产出与质量结果 |
| 今日合格率 | ≥95% 显示绿色，偏低橙色预警 |
| 在制工单 | 当前正在生产的工单数 |
| 待检检验单 | 质量环节积压量（持续偏高=检验瓶颈） |
| 停工中 / 未关闭异常 | 现场异常水平（红色，需关注） |

### 2.2 近 7 日产量趋势

每日合格数/不良数/合格率列表，合格率 ≥95% 绿色。看趋势比看单日更有意义——连续走低先查不良 TOP。

### 2.3 不良原因 TOP（近 7 日）

出现频次最高的前 10 类不良。经营判断：TOP1 不良是否集中在某类产品/工序 → 让车间主任/质检员专项改善。

### 2.4 设备维修统计（近 30 日）

每台设备的维修次数与停机分钟数。频繁维修设备是更换/大修信号。

## 三、AI 生产日报

看板报表 →「**AI 生成日报**」→ 系统汇总近 1 日产量、合格率、异常、停机等数据生成日报草稿 → 弹窗展示，可「复制内容」转发到管理群/邮件。**日报为草稿**，正式发布前请人工核对数据。

## 四、AI 智能问数（自然语言查数据）

看板报表顶部输入框，直接用大白话提问，回答由 AI 平台调用 MES 受控数据工具生成（只读、可复制）。常见用法：

| 想知道 | 可以这样问 |
| --- | --- |
| 未完成工单有哪些 | 「未完成工单有哪些」 |
| 质量水平 | 「上周合格率」「本月不良 TOP」 |
| 产能情况 | 「近 7 天各产线产量」 |
| 现场状态 | 「当前在制品分布」「停工中的工单」 |

> 提示：AI 只读受控供数（不直接连库），答案基于统计口径聚合，与看板同源；重要汇报请与看板数字交叉核对。

## 五、追溯取证

客诉/审计场景：追溯查询 → 输入成品批次号 →「追溯」→ 查看来源、工单、工序报工链、耗用原料 →「**导出报告**」下载 CSV。这是管理层少数需要动手的操作，可自行完成，无需依赖车间。

## 六、管理例会建议用法

1. **晨会（3 分钟）**：六卡指标 → 有红先处理（停工中/未关闭异常、待检积压）。
2. **周会**：近 7 日趋势 + 不良 TOP + AI 日报数据，定改善主题。
3. **月度**：设备维修统计安排设备投资/大修；追溯报告抽查留档。

## 七、注意事项

1. 管理层角色**只读**：看不到新增/修改按钮是设计如此；如需操作权限请兼授对应业务角色。
2. AI 日报/问数输出均有「AI 生成，仅供参考」标注，对外发布前请核对。
3. 统计口径：今日/近 7 日/近 30 日三档，例会引用时注意说明时间范围。
4. AI 能力未开启时（按钮置灰），请 MES 系统管理员开启 `mes.ai.mode`。
