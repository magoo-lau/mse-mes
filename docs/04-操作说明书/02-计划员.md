# 02 计划员操作手册

> 角色：`mes_planner`｜数据范围：本部门及以下｜可见菜单：基础数据（只读）、生产计划、生产执行（进度只读）、看板报表。
> 定位：生产订单与排产的主人——从工单创建、下达、排产发布到 AI 排产建议，把「卖什么」变成「产线怎么干」。

## 一、职责与页面清单

| 页面 | 你能做什么 |
| --- | --- |
| 基础数据 | 只读查询物料、BOM、工艺路线、日历班次（建模维护找 MES 系统管理员） |
| 生产计划 | 生产订单全流程（创建/提交/下达/取消/关闭/删除、批量流转）、排产计划（新增/编辑/发布/删除）、AI 排产建议 |
| 生产执行 | 只读查看生产进度 |
| 看板报表 | 看板指标、AI 智能问数 |

## 二、典型流程

### 2.1 从订单到开工（主线流程）

1. 建单：生产计划 →「生产订单」页签 →「**新建工单**」→ 选产品、BOM（可选）、工艺路线（只列已发布路线）、计划数量、计划开始/完成日期 → 保存。工单为**草稿**态，可反复编辑。
2. 提交：草稿核对无误后点行内「**提交**」，进入**已提交**（此状态不可再编辑/删除，只能下达或取消）。
3. 下达：点行内「**下达**」→ 系统按工单的工艺路线**自动展开各工序的派工单**，进入**已下达**，车间可开始派工。
4. 排产：切到「**排产计划**」页签 →「**新增排产**」→ 选工单（只列已提交/已下达的）、产线、日期、班次（白班 D / 夜班 N）、计划数量 → 保存（草稿态）→ 核对后行内「**发布**」或勾选后「**批量发布**」。**发布后排产才对车间生效**。
5. 跟踪：到「生产执行 → 生产进度」查看工单/工序的 完工数/合格数/不良数 与各工序报工进度。

### 2.2 订单的取消、关闭与删除

| 状态 | 可用操作 | 说明 |
| --- | --- | --- |
| 草稿 | 编辑、提交、取消、删除 | 反复修改直至确认 |
| 已提交 | 下达、取消 | 不可编辑；取消即终止 |
| 已下达 / 生产中 | 关闭 | 生产中订单走「关闭」收口 |
| 完工 / 已关闭 / 已取消 | 无操作 | 只读留档 |

- 工具栏提供「**批量提交 / 批量下达 / 批量取消 / 批量关闭 / 批量删除**」：勾选多行后执行，状态不允许的行自动跳过并说明原因（批量删除仅草稿可删）。

### 2.3 AI 排产建议（可选辅助）

1. 「排产计划」页签 →「**AI 排产建议**」→ 弹窗自动生成草稿（仅**已下达/生产中**的工单参与），表格含：工单、产线、日期、班次、计划数、AI 理由。
2. **勾选**认可的建议行 → 点「**应用选中项**」→ 确认后写入排产计划（草稿态，备注自动带「AI 建议：…」）。
3. 到排产列表对这些草稿行执行「发布」才真正生效。
4. AI 结果仅供参考：没有待排工单、生成失败都有明确提示；应用后仍可编辑/删除草稿再发布。

## 三、页面操作详解

### 3.1 生产计划 → 生产订单页签

- 筛选：工单号、状态。
- 列：工单号、产品、计划数、完工数、合格数、不良数、计划开始/完成、状态。
- 新建/编辑工单字段：产品（必填）、BOM（可选）、工艺路线（可选，仅已发布）、计划数量（必填，≥1）、计划开始、计划完成、备注。

### 3.2 生产计划 → 排产计划页签

- 筛选：产线。
- 列：日期、班次、产线、工单、计划数、状态（草稿/已发布）。
- 行内操作仅草稿态可见：编辑、发布、删除；工具栏「新增排产」「AI 排产建议」「批量发布」。
- 排产是「产线 × 班次 × 日期」的粒度，同一工单可拆多行排产。

### 3.3 AI 智能问数（看板报表页）

顶部「AI 智能问数」输入框直接用自然语言提问，例如：

- 「未完成工单有哪些」
- 「上周三车间合格率」
- 「近 7 天各产线产量」

系统经 AI 平台调用 MES 受控数据工具回答，答案弹窗展示并可复制。**AI 只读不写**，适合快速核对进度、统计口径；正式报表仍以看板数据为准。

## 四、注意事项

1. **下达即锁定**：已下达/生产中的工单不能编辑与删除，只能取消（已下达前）或关闭（已下达后）；改计划需与调度员/车间主任协调。
2. **工艺路线先发布**：建单时选不到路线，多半是路线还在草稿态——找 MES 系统管理员发布。
3. **排产要发布**：草稿排产车间看不到、也不参与产能口径；发布前确认产线、班次、数量无误。
4. **AI 只出草稿**：排产建议应用后仍是草稿态，发布动作必须人工完成。
5. 数据范围是「本部门及以下」：跨部门车间的工单/排产不可见属正常。
